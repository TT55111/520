# 520 情侣纪念网站 - 设计文档

> 创建日期：2026-05-20
> 项目类型：情侣纪念网站（全新项目）
> 恋爱开始日期：2025-09-28

---

## 一、项目背景

这是一个给恋人使用的私人纪念网站，主题围绕"520"打造浪漫氛围。
核心目的：记录我们在一起的点点滴滴，让爱情可视化。

---

## 二、需求描述

### 2.1 核心功能

| 功能 | 描述 |
|------|------|
| **纪念日计时** | 首页醒目展示"我们已经在一起 X 天 XX 时 XX 分 XX 秒"，精确到秒并实时更新。基于恋爱开始日期 2025-09-28 自动计算。 |
| **照片上传与展示** | 支持上传多张照片（可拖拽上传），自动生成专属相册。瀑布流/网格布局，点击可放大预览，支持删除。 |
| **浪漫互动元素** | 页面加入背景音乐，动态爱心动画效果（心跳感、漂浮粒子）。 |

### 2.2 非功能需求

- 主色调：粉色系浪漫风格
- 布局风格：方案 A - 经典中心式（居中布局，首屏冲击力强）
- 单页滚动式结构，无需多页面

---

## 三、方案选项

### 布局方案选择

| 方案 | 风格 | 特点 | 选择 |
|------|------|------|------|
| A | 经典中心式 | 名字+爱心+计时器居中，下方照片墙 | ✅ 已选 |
| B | 杂志风格 | 大图+文字+数据模块化排版 | |
| C | 时间轴叙事 | 时间线为主线展示故事 | |

### 存储方案

| 方案 | 描述 | 优缺点 | 选择 |
|------|------|--------|------|
| LocalStorage/IndexedDB | 纯前端本地存储 | 简单无需后端，但数据不跨设备 | ✅ 已选 |
| 后端 + 数据库 | 上传到服务器 | 数据持久化但需要后端 | |

## 五、技术选型

### 5.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | Astro + Tailwind CSS | 与现有项目技术栈一致 |
| 样式 | Tailwind CSS | 快速构建粉色系浪漫风格 |
| 计时器 | JavaScript setInterval | 每秒更新一次 |
| 照片存储 | IndexedDB (localforage) | 本地存储，支持二进制数据 |
| 照片上传 | HTML5 Drag & Drop API | 原生拖拽上传 |
| 动画 | CSS Animation + JS 粒子 | 心跳动画 + 漂浮爱心 |
| 音乐 | HTML5 Audio | 原生播放器 |
| 图片预览 | 自定义 Modal | 点击放大，ESC 关闭 |

### 5.2 颜色方案


## 六、组件设计

### 6.1 Hero 组件

- **职责**：展示两人名字、动态爱心、恋爱计时器
- **输入**：恋爱开始日期、两人名字（可配置）
- **输出**：实时更新的计时显示
- **依赖**：Date API

### 6.2 照片墙组件

- **职责**：照片展示、上传、预览、删除
- **输入**：照片数据数组
- **输出**：网格/瀑布流布局的照片墙
- **交互**：
  - 拖拽上传 → 保存到 IndexedDB
  - 点击照片 → 放大预览 Modal
  - 长按/右键 → 删除照片
- **依赖**：localforage、HTML5 File API

### 6.3 爱心动画组件

- **职责**：页面背景漂浮爱心动画
- **类型**：
  - 心跳动画：居中大爱心，模拟心跳效果
  - 漂浮粒子：随机生成小爱心，向上漂浮消失
- **性能**：使用 CSS transform 和 opacity，GPU 加速

### 6.4 音乐播放器组件

- **职责**：背景音乐控制
- **功能**：播放/暂停、音量控制
- **交互**：底部固定栏，可收起

## 七、数据流

```
用户操作 → 组件处理 → 状态更新 → 视图渲染
   │                           │
   ↓                           ↓
照片上传 → IndexedDB → 照片墙重渲染
拖拽文件 → File API → localforage.set()

```

## 九、风险点

| 风险 | 影响 | 应对方案 |
|------|------|----------|
| 浏览器本地存储容量限制 | 照片数量受限 | 使用 IndexedDB（通常 50MB+），压缩上传照片 |
| 跨设备数据不同步 | 换设备后照片丢失 | 纯本地方案，暂不做云同步 |
| 音乐自动播放限制 | 部分浏览器阻止自动播放 | 首次点击页面后触发播放 |
| 动画性能 | 低端设备可能卡顿 | 控制粒子数量（≤30个），使用 requestAnimationFrame |

## 十、验收标准

1. 打开页面即可看到恋爱计时器，每秒实时更新
2. 计时器基于 2025-09-28 00:00:00 精确计算
3. 支持拖拽多张照片到上传区域
4. 照片以网格/瀑布流形式展示
5. 点击照片可放大预览，ESC 或点击外部关闭
6. 支持删除照片
7. 页面有动态爱心动画效果
8. 支持背景音乐播放控制
9. 整体风格为粉色浪漫系
10. 响应式适配，手机端正常显示
